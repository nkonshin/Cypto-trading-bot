# Копирование сделок со стрима RastPentagon → BingX

Дата: 2026-11-25. Статус: согласовано с Никитой (полный автомат на живые деньги, уведомления в Telegram).

## Зачем

Раст ведёт публичный разгон депозита ($1000) на Twitch 24/7. Сделки он нигде не публикует, только показывает
в эфире. Нужно, чтобы его позиции автоматически и пропорционально повторялись на BingX Никиты.

## Решения Никиты (25.11)

- Автоматически копируется только BTC. Остальные монеты приходят в Telegram с кнопками «Открыть» и
  «Пропустить» (15 мин). После подтверждения копия ведётся автоматически.
- Ручные позиции Никиты бот не трогает никогда: он управляет только тем, что открыл сам. Режим позиций счёта
  (hedge/one-way) бот не меняет.
- Объём — в пропорции **текущих** балансов: его объём × (наш баланс / его «Assets Value») × множитель
  (по умолчанию 1.0). Его баланс читается при каждом изменении панели и не старше 15 мин.
- Ручные закрытия Раста ловятся по панели. TP/SL копируются стоп-ордерами.
- Пауза «руки прочь» на 1 ч / 4 ч / до 23:00 / без срока (с напоминанием раз в 3 ч). В паузе бот только пишет.
  После паузы и при старте приходит сверка: позиции Раста без копии — «Открыть?», наши копии, которые он уже
  закрыл, — «Закрыть / Оставить себе», копии, изменённые руками, считаются твоими.

## Цели и анти-цели

- Открытие, закрытие, изменение объёма и переворот копируются сами. TP/SL копируются стоп-ордерами.
- **Анти-цель:** торговать по ошибке распознавания. Если бот не уверен, он ничего не делает.
- **Анти-цель:** доступ к копированию у отца. Все команды только для `main_user_id`.
- Не цель: копировать его лимитные ордера (на экране видны только позиции и TP/SL).

## Подходы

- **A. Читать видео стрима и распознавать текст на панели позиции (выбран).** Копитрейдинга и публичного API у него нет.
- B. Читать чат (модератор дублирует позицию текстом). Ненадёжно и с задержкой, годится только как подсказка.
- C. Полуавтомат с кнопкой подтверждения. Никита выбрал полный автомат.

## Устройство

Отдельный контейнер `copier` в репозитории крипто-бота (`copytrade/`) на VPS в Амстердаме.

1. **Поток.** GQL-токен Twitch с `playerType=embed`: у `site` предролл-реклама, у `embed` её нет (проверено 25.11).
   ffmpeg декодирует только ключевые кадры (`-skip_frame nokey`, кадр раз в 2 с), 1720×720.
2. **Распознавание.** RapidOCR (onnxruntime, CPU) на вырезке панели позиции (275,428,350,190) и баланса
   (275,630,280,60) в координатах 1720×720, увеличенных в 2 раза. На 1 vCPU уходит около 2 с на вырезку, поэтому
   распознаём только при изменении пикселей в зоне статичных полей и раз в 30 с для контроля.
3. **Разбор.** Вкладка `Position (N)`, карточки по якорю `Perpetual`: монета, сторона (`Short`/`Long`
   нечётко), объём (`Positions (BTC)`), средняя цена, маржа (из неё плечо = номинал/маржа), строка TP/SL
   `All Positions a ($)/b ($)`. Числа принимаются только при уверенности ≥ 0.9 и строгом формате.
   Чтение считается годным, только если N совпадает с числом полностью разобранных карточек, а монета есть
   на BingX. Иначе бот «слепой».
4. **Подтверждение.** Набор позиций (монета, сторона, объём) должен совпасть в 2 годных чтениях подряд.
   TP/SL подтверждаются отдельно (2 одинаковых непустых значения), пропуски их не сбрасывают.
5. **Исполнение.** Объём = его позиции × k, округлённые вниз до шага лота. Меньше минимального
   лота → 0 с предупреждением. Бот сверяет цель с фактической позицией на BingX и ставит дельту рыночным
   ордером (уменьшение с `reduceOnly`). Изолированная маржа, плечо как у него. Если маржи не хватает,
   объём ужимается до 95% доступной. TP/SL — стоп-ордерами на всю позицию, при изменении пересоздаются.
6. **Позиции, открытые до старта или во время паузы**, не догоняются сами — только через кнопку сверки.
7. **Слепота** (стрим упал, другая сцена, панель не найдена): никаких действий, позиции стоят под
   скопированным стопом. Уведомление через 3 мин и при восстановлении.

## Режимы и Telegram

- Режимы: `off` (только смотрит), `notify` (пишет, что сделал бы), `demo` (торгует на демо BingX VST),
  `live` (живые деньги). После деплоя стоит `notify`. Переключает Никита.
- Связь с крипто-ботом через общий том `copier-data`: `settings.json` (режим, k, флаги, команды) пишет бот,
  `status.json` пишет копировщик. Уведомления копировщик шлёт сам через Bot API (`sendMessage`,
  без polling — конфликта с ботом нет) на `main_user_id`.
- Команды бота, только для админа: `/copy` (статус, режим, пауза, множитель, «закрыть копии»),
  `/copy_mult 1.2`, `/copy_mode live`. Кнопки уведомлений (`copy:offer:<id>:yes|no`) обрабатывает бот и
  передаёт командой в `settings.json`.

## Ограничения

- Задержка от его клика до нашего ордера около 8–12 с (стрим ~2–3 с, ключевой кадр ≤2 с, распознавание
  2×2 с, ордер). Для его сделок на часы приемлемо, для скальпа нет.
- Видна одна карточка позиции. Если позиций больше, чем видно, бот слепнет и сообщает.
- Ключ BingX: только торговля, без вывода, привязка к IP 72.56.85.245, лучше отдельный субаккаунт.
